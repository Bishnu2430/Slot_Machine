# Slot Machine Game 🎰

A simple and fun slot machine game built with Python! Test your luck and see if you can win big!

## Features
- **Customizable Betting**: Choose your bet per line and number of lines (up to 3).
- **Random Spins**: Enjoy randomized outcomes with different symbols.
- **Win Multipliers**: Each symbol has unique values to multiply your winnings.
- **Track Your Balance**: Start with a deposit and manage your funds as you play.

## How to Play
1. Run the script in your Python environment.
2. Deposit money to start playing.
3. Select the number of lines to bet on (1-3).
4. Set your bet amount per line.
5. Spin the slot machine and check your winnings!
6. Continue playing or exit the game at any time.
